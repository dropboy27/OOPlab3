# Лабораторная работа 3 - QuadraticSet вариант 16

Множество квадратных трёхчленов с динамическим массивом и перегрузкой операторов.

## Сборка проекта


```bash
mkdir build
cd build
cmake ..
make
```

## Запуск тестов

Из папки `build`:

```bash
./run_tests
```

## Запуск  программы

```bash
cmake ..
make
./lab3_app
```

## После изменения кода

```bash
make
./run_tests
```
